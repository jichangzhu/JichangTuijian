## 对比维度（选购必读）

选机场时优先盯这几项，而不是协议名词：

1. **线路形态**：中转机场通常带宽更大、体验更稳；专线侧重低延迟。直连与中转各有取舍，长期使用更建议中转或专线。
2. **总带宽与上游质量**：速度看总带宽；稳定看上游与落地资源，不单看广告文案。
3. **解锁能力**：流媒体 / ChatGPT 等取决于落地与解锁商，以下文案来自各场简介，以实测为准。
4. **备用策略**：经常使用时不要单押一家，建议准备 2 个以上备用订阅。
5. **协议权重**：对中转场来说，机房稳定性与带宽往往比「用了什么协议」更关键。
